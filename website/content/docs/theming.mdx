One file holds every colour: `lib/apexrn/colors.ts`, copied into your app by `npx apexrn init`. Parts read colours from the theme and never contain a hex value, so editing that file restyles everything.

## Edit the tokens

Open `colors.ts` and change the values of the preset you use. Keep each foreground token readable on its fill; the library checks 4.5:1 contrast for every pair.

```ts title="lib/apexrn/colors.ts"
const neoLight: ColorScheme = {
  background: '#FFFFFF',
  primary: '#FF5252', // change the value, every part follows
  // ...
};
```

Pick the preset on the provider: `<ApexRNProvider preset="raw">`. The default is neo.
